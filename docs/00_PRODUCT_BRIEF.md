# PersonaBench Product Brief

## Name

PersonaBench

## Tagline

Don’t guess. Interview persona agents.

## Elevator pitch

PersonaBench runs data-grounded synthetic personas through your product, records where they hesitate or drop off, asks them post-session interview questions, and turns every UX failure into a fix prompt for your coding agent.

## Audience

### Developers

Developers use PersonaBench as UX CI:

- run persona tests against local or staging URLs
- get replay-backed findings
- generate fix prompts
- rerun after changes

### PMs / Designers / UX Researchers

Non-developers use the web UI:

- select target markets and persona packs
- run tests against product flows
- watch session replays
- review interviews and findings
- create tickets for developers

### Enterprise buyers

Enterprise teams buy:

- hosted dashboard
- private runners
- custom persona libraries
- audit logs
- retention controls
- SSO/RBAC
- self-hosted or VPC deployment

## Product promise

Before users struggle in production, persona agents struggle in your test environment.

## Product boundaries

PersonaBench is not a replacement for real user research. It is a pre-research and pre-release screening system that helps find obvious UX friction earlier.

## Key differentiator

Most AI persona tools start with a prompt.

PersonaBench starts with a persona record from a dataset such as NVIDIA Nemotron-Personas, then compiles that record into a UX behavior agent.

## Primary workflow

```txt
Select persona source
  -> search / filter / sample personas
  -> compile persona agents
  -> run product task
  -> record session
  -> detect friction
  -> interview persona
  -> generate findings
  -> send fix to coding agent
  -> rerun UX regression
```
